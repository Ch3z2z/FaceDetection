# Denis Face Detection

Приложение для обнаружения ключевых точек лица на Android с использованием обученной TensorFlow Lite модели.

## Описание проекта

Приложение использует камеру устройства в реальном времени для обнаружения лиц и определения 15 ключевых точек на каждом лице. Процесс включает:

1. **Обнаружение лиц** с помощью Google ML Kit Face Detection
2. **Кропирование** обнаруженных лиц  
3. **Предсказание ключевых точек** с помощью обученной TensorFlow Lite модели
4. **Отображение** результатов в виде ограничивающих рамок и точек на экране

## Технологии

- **Язык программирования**: Kotlin
- **Платформа**: Android
- **Обнаружение лиц**: Google ML Kit Face Detection
- **Машинное обучение**: TensorFlow Lite
- **Работа с камерой**: AndroidX Camera
- **UI**: ViewBinding, Canvas API

## Требования

- Android 7.0 (API 24) и выше
- Камера с фронтальной или задней камерой
- Разрешение на использование камеры

## Как работает приложение

1. **Запуск камеры**: Приложение запрашивает разрешение на доступ к камере
2. **Обработка кадров**: Каждое изображение с камеры обрабатывается в реальном времени
3. **Обнаружение лиц**: Используется Google ML Kit для обнаружения лиц в кадре
4. **Предсказание точек**: Для каждого обнаруженного лица:
   - Кропится область лица
   - Масштабируется до 96x96 пикселей
   - Передается в TensorFlow Lite модель
   - Модель возвращает 15 ключевых точек (30 значений: x1,y1,x2,y2...)
5. **Отображение**: Результаты рисуются поверх видеопотока

## Компоненты

### MainActivity.kt
- Управляет жизненным циклом приложения
- Запрашивает разрешения камеры
- Инициализирует и настраивает CameraX

### FaceAnalyzer.kt
- Реализует ImageAnalysis.Analyzer
- Обрабатывает кадры с камеры
- Координирует работу детектора лиц и модели ключевых точек
- Поворачивает изображения для правильной ориентации

### KeypointModel.kt
- Загружает TensorFlow Lite модель из assets
- Предобрабатывает изображения (масштабирование, нормализация)
- Выполняет предсказание ключевых точек
- Возвращает массив из 30 значений (15 точек x,y)

### FaceOverlayView.kt
- Кастомный View для отображения результатов
- Рисует ограничивающие рамки вокруг лиц
- Отображает ключевые точки лица красными точками
- Автоматически масштабирует под размер экрана

## Модель

- **Файл**: `facial_keypoints_model.tflite`
- **Вход**: Изображение 96x96 пикселей в градациях серого
- **Выход**: Массив из 30 значений (15 точек x,y в диапазоне 0-96)
- **Архитектура**: Обученная нейронная сеть для детекции ключевых точек лица

## Использование

1. Склонируйте репозиторий
2. Откройте проект в Android Studio
3. Соберите и установите приложение на устройство
4. Запустите приложение и разрешите доступ к камере
5. Направьте камеру на лицо - приложение автоматически обнаружит ключевые точки

## Особенности

- **Реальное время**: Обработка происходит в реальном времени
- **Мультизадачность**: Может обнаруживать несколько лиц одновременно
- **Кроссплатформенная камера**: Поддержка как передней, так и задней камеры
- **Эффективность**: Оптимизированная работа с TensorFlow Lite

3. Или установите через Android Studio
